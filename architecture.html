Local document corpus with cosine similarity ranking. Safe stop triggers if search returns zero relevance.

⚖️ Zero-Hallucination Critic Fact-Check Gate

Specialist Agent Roster & Dual-Tool Architecture

Each specialist module encapsulates exactly two canonical Python tools, accessible directly and exposed via Microsoft Semantic Kernel plugins.

1. Planner / Query Agent agents/planner_agent.py

Decomposes raw research questions into domain keywords and structured sub-questions.

Canonical Python Tools:
extract_keywords(text) generate_subquestions(question)
Fallback Specialist: FallbackPlannerAgent (heuristic keyword extraction)
2. Research / Retrieval Agent agents/research_agent.py

Searches peer-reviewed academic documents via TF-IDF vector space model and extracts passage excerpts.

Canonical Python Tools:
search_documents(corpus, query) retrieve_passages(doc_id)
Fallback Specialist: FallbackRetrievalAgent (broad-string matching)
3. Analysis / Summary Agent agents/analysis_agent.py

Groups findings into thematic clusters (Learning Support, Teacher Workflow, Risks) and extracts candidate claims.

Canonical Python Tools:
group_findings_by_theme(evidence) compare_evidence(claims)
Performative: Emits PROPOSE with candidate claims and provisional citations.
4. Reviewer / Fact-Check Agent (Critic) agents/reviewer_agent.py

Zero-hallucination critic gate. Verifies whether candidate claims have exact matching quotes in retrieved evidence.

Canonical Python Tools:
verify_citations(claims, evidence) detect_unsupported_claims(claims)
Critic Decisions: CONFIRM (Pass to Writer) or DISCONFIRM (Prune to dropped claims).
5. Writer Agent agents/writer_agent.py

Formats final structured Markdown academic report and guarantees 100% cited ID matching against evidence.

Canonical Python Tools:
format_research_report(state) validate_report_sources(report, evidence)
Citation Gate: Safely aborts if an unregistered citation ID appears in the output.
6. Coordinator & State Machine coordinator.py & production_coordinator.py

Central engine driving state machine transitions, 2x retry backoff policies, audit JSONL logging, and dynamic reassignments.

Core Capabilities:
ResearchState dataclass Append-only run.jsonl Semantic Kernel Plugins
Status Enums: initialized, success, stopped_no_evidence, stopped_report_validation_failed, stopped_agent_failure.

FIPA-ACL Performative Taxonomy

Performative Sender → Receiver Semantics
REQUEST Coordinator → Agent Instructs agent to execute subtask
INFORM Agent → Coordinator Returns computation results
QUERY Research → Corpus Retrieval vector search
PROPOSE Analysis → Reviewer Submits candidate claims
CONFIRM Reviewer → Coordinator Critic approves grounded evidence
DISCONFIRM Reviewer → Coordinator Critic rejects ungrounded claims
FAILURE Agent → Coordinator Unrecoverable execution exception
REASSIGN Coordinator → System Dynamic specialist substitution

Production Fault Tolerance & Critic Gate Rules

Matrix of failure scenarios, triggers, automated system actions, and verified academic outcomes.

Failure Scenario Trigger Condition System Action System Outcome
Transient Agent Exception Temporary Python exception during step Coordinator catches error, logs in run.jsonl, increments attempt counter, and retries up to 2 times. Auto Recovers Task succeeds on retry without halting pipeline.
Permanent Agent Failure Agent crashes after all retry attempts Production Coordinator triggers REASSIGN speech act to secondary specialist (e.g. FallbackPlannerAgent). Dynamic Reassignment Execution continues with graceful degradation.
Out-of-Domain Query Query matches 0 documents (cosine similarity <= 0) Retrieval agent returns empty evidence set; Coordinator initiates clean Safe Stop. Safe Stop Status set to stopped_no_evidence. Zero hallucinations produced.
Ungrounded Candidate Claim Claim lacks exact verbatim quote in cited source Fact-Check Agent issues DISCONFIRM verdict; claim is pruned from body and added to dropped claims list. Pruned & Audited Final brief explicitly records "Unsupported claims dropped".
Citation ID Mismatch Final brief references an ID not in retrieved evidence Writer source validator triggers hard rejection; Coordinator halts delivery. Integrity Safe Stop stopped_report_validation_failed protects academic integrity.
